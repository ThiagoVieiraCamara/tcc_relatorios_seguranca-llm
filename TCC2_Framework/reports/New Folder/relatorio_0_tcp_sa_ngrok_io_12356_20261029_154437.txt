3. RECOMENDACOES DE MITIGACAO
   * **Header ausente: Content-Security-Policy:** Implementar o header HTTP Content-Security-Policy com políticas adequadas para restringir as fontes de conteúdo confiáveis e prevenir a execução de scripts não autorizados.
   * **CORS permissivo:** Restringir o valor do header 'Access-Control-Allow-Origin' para permitir apenas as origens confiáveis que necessitam de acesso.
   * **Metodo HTTP habilitado: PUT:** Desabilitar métodos HTTP que não são estritamente necessários, como o PUT, ou restringir o seu uso a caminhos específicos e com autenticação adequada.
   * **Metodo HTTP habilitado: DELETE:** Desabilitar métodos HTTP que não são estritamente necessários, como o DELETE, ou restringir o seu uso a caminhos específicos e com autenticação adequada.
   * **Header ausente: Strict-Transport-Security:** Configurar o servidor para enviar o header HTTP Strict-Transport-Security com uma diretiva de tempo de vida (max-age) adequada para forçar o uso de conexões HTTPS.
   * **Header ausente: Referrer-Policy:** Implementar o header HTTP Referrer-Policy para controlar quais informações de referência são enviadas com as requisições.
   * **Header ausente: Permissions-Policy:** Configurar o header HTTP Permissions-Policy para especificar quais recursos e APIs do navegador o dispositivo pode acessar.
